# Banking Financial Performance

Banking & financial services intelligence presented as a responsive, interactive dashboard.

## Eight dashboard pages
1. Executive Summary
2. Deposits
3. Loan Portfolio
4. Net Interest
5. Credit Quality
6. Branches
7. Customers
8. Risk Monitor

## Included
- Eight navigable dashboard pages
- KPI cards, SVG trend charts, contribution bars and detail tables
- Responsive desktop and mobile layout
- Lightweight HTML, CSS and JavaScript; no build tools or external libraries
- Period selector and dashboard navigation

## Run
Open `index.html` in a modern web browser.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then save.
